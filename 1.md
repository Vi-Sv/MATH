БЛОК 2. ПОШАГОВЫЙ АЛГОРИТМ РЕШЕНИЯ (ДВИЖОК ВЫЧИСЛЕНИЙ)
================================================================================

--------------------------------------------------------------------------------
ШАГ 2.1. Расчет ОДЗ (Переменная: РАБОЧИЕ_МЕСТА)
--------------------------------------------------------------------------------
IF Гёометрия == "ЛИНИЯ":
    РАБОЧИЕ_МЕСТА = N - (Размерность окна - 1)
    /* Исключаем граничные элементы, у которых окно "вылезает" за край ряда */

IF Геометрия == "КРУГ":
    РАБОЧИЕ_МЕСТА = N
    /* Границ нет, кольцо замкнуто, все элементы имеют полный набор соседей */

--------------------------------------------------------------------------------
ШАГ 2.2. Расчет вероятности одной точки (Переменная: ШАНС_УСПЕХА)
--------------------------------------------------------------------------------
Выделяем ОДНО изолированное окно в середине контура.
Определяем комбинации элементов, удовлетворяющие условию "красоты".

Для каждой успешной комбинации считаем вероятность пошагово (Логика конвейера):

Позиция 1 (Базовая): 
  Шанс_1 = (Остаток_нужного_типа) / N
Позиция 2 (Зависимая): 
  Шанс_2 = (Остаток_нужного_типа - Израсходовано) / (N - 1)
Позиция 3 (Зависимая): 
  Шанс_3 = (Остаток_нужного_типа - Израсходовано) / (N - 2)

Шанс_Комбинации = Шанс_1 × Шанс_2 × Шанс_3

IF Успешных комбинаций несколько (например, "Все_А" ИЛИ "Все_Б"):
    ШАНС_УСПЕХА = SUM(Шанс_Комбинации_1 + Шанс_Комбинации_2 + ...)

--------------------------------------------------------------------------------
ШАГ 2.3. Результирующий конвейер (Переменная: МАТ_ОЖИДАНИЕ)
--------------------------------------------------------------------------------
МАТ_ОЖИДАНИЕ = РАБОЧИЕ_МЕСТА × ШАНС_УСПЕХА

БЛОК 3. ВЕРИФИКАЦИЯ И КАПКАНЫ (ОТК)
================================================================================
3.1. Капкан асимметрии :: Проверить, все ли РАБОЧИЕ_МЕСТА находятся в одинаковых 
                          условиях. Если условия на краях линии разные — 
                          считать края отдельно через аналог оператора CASE WHEN.
3.2. Капкан остатка     :: Проверить, уменьшался ли знаменатель на каждом шаге 
                          извлечения (N -> N-1 -> N-2). Если объекты возвращаются 
                          назад в бак — знаменатель жестко константен (N).
